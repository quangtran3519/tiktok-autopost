TikTok Autopost

TikTok Autopost is a personal tool that runs on the owner's own computer. It watches a folder for new videos and uploads them to the owner's TikTok account using TikTok's Content Posting API.

The owner signs in with TikTok through Login Kit. A local dashboard shows each video's upload status, lets the owner edit captions before upload, and retry videos that failed.

This tool is not offered to the public. It only posts to the account of the person running it.
